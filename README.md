# Google Ads Calculator

Simulateur & calculateur d'estimations pour campagnes Google Ads (PPC).

## 🎯 Objectif

Fournir un outil d'estimation interactif, rapide et accessible pour modéliser les métriques clés de campagnes Google Ads (CPC, CTR, CPA, ROAS, conversions, budget recommandé).

## 🛠️ Stack technique

- **Framework :** [Astro](https://astro.build/) (mode statique / SSG)
- **Langage :** [TypeScript](https://www.typescriptlang.org/)
- **Design & Styles :** [Open Props](https://open-props.style/) & CSS moderne

## 🌿 Stratégie Git & Branches

- `main` : Branche de production / stable
- `development` : Branche de travail active et intégration des fonctionnalités

## 🚀 Démarrage local

```bash
# Installation des dépendances
npm install

# Démarrage du serveur de développement
npm run dev

# Build de production
npm run build
```
